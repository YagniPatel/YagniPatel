## 🚀 Featured AI Projects

### 🔐 [Multimodal Phishing Webpage Detection](https://github.com/YagniPatel/phishing_webpage_detection_using_multimodal)
Fine-tuned RoBERTa + ResNet50 late-fusion architecture on 5,000 labeled Phishpedia webpages. Text-only model achieved 97% accuracy (FNR 1.55%). Investigated why multimodal fusion failed to beat the text baseline — identified modality imbalance as the root cause.

### 🎯 [LLM Calibration via Self-Evaluation](https://github.com/YagniPatel/llm-calibration-self-evaluation)
Built a self-evaluation framework to extract confidence scores from LLM self-judgment logits on TriviaQA. Applied temperature scaling to reduce ECE from 0.217 → 0.132 (Qwen-2.5-1.5B). Found that stronger discriminative ability (AUROC) doesn't imply better calibration.

### 🛡️ [Breaking and Securing LLMs](https://github.com/YagniPatel/breaking-securing-llms)
Evaluated PAIR, GCG, and Prompt-RS attacks against LLaMA-3.1, LLaMA-4, and Qwen3-32B. Prompt-RS hit 99% ASR on Llama models. Designed a two-stage defense pipeline (prompt sanitization + LlamaGuard) achieving 95% Defense Block Rate across all attack paradigms.
